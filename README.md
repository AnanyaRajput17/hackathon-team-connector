A robust REST API built with Java Spring Boot designed to help students and developers find teammates, manage hackathon registrations, and communicate effectively during build-a-thons.

🚀 Features
User Authentication: Secure login and registration using Spring Security.

Team Management: Create teams, send join requests, and manage team members.

Hackathon Listings: View upcoming hackathons and track participation.

Real-time Chat: Integrated WebSocket support for instant team communication.

Skill Matching: Filter potential teammates based on specific technical stacks.

🛠️ Tech Stack
Language: Java 17+

Framework: Spring Boot 3.x

Security: Spring Security & JWT (JSON Web Tokens)

Real-time: Spring WebSocket

Database: PostgreSQL (JPA/Hibernate)

Build Tool: Maven
